# 人生审核站 · p5.js + ml5.js 原型

包含定制印章素材与本地 Joystix 字体。使用 p5.js 2.0.5、ml5.js 1.3.1 / MoveNet，首次运行需要联网加载库与模型。摄像头在浏览器本地处理，不上传、不保存视频。审核回答仅保留在当前页面内存。

## 启动

推荐双击本目录的 `启动原型.command`，服务绑定成功后会打开浏览器。体验期间保持该终端窗口打开；关闭或按 Control-C 会停止网站。重启电脑后再次双击启动即可。


在本目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，浏览器打开 http://localhost:8765 。请不要直接双击 HTML，摄像头需要 localhost 或 HTTPS。

1. 先点击“Try demo ↗”，鼠标进入画面中间，停留 1.5 秒开始。按 Y / N 回答四轮问题；鼠标离开画面 2 秒自动重置。R 重新开始。
2. 点击“Start camera”，允许摄像头访问，等待模型加载。让肩膀和上半身入镜。在中间区域停留后，举起画面左侧手表示已完成，右侧表示未完成，保持 0.7 秒，下一题前放下双手；也可点击按钮。
3. 展开右下角“PROJECTOR / SETUP ↗”，点击“Open projector ↗”，将窗口移动到扩展模式的投影仪上，双击全屏。显示器保留主窗口。投影窗口黑底，只显示印章；丢失同步 1.5 秒后自动黑屏。
4. 展开校准，打开网格，对准固定站位者胸前，调水平、垂直、大小，完成后关闭网格。身体投影请避开眼睛。

## 当前边界

- 单人、固定站位体验；多人同时入镜可能切换追踪对象。
- 默认固定位置投印章。实验性的胸口跟随只有偏移/缩放补偿，不是三维投影映射；保持固定深度与正面朝向。
- 不识别实际年龄、学历、婚姻或生育情况；审核完全依据按钮或手势选择。
- 浏览器窗口需要手动摆放到两块输出设备。摄像头画面已镜像，投影追踪可单独反转。
- 主窗口需要持续可见；避免最小化或切到其他标签导致浏览器降频。
- 实机的摄像头、模型速度、光线和投影位置需现场验证。

## 文件

`index.html` 页面，`style.css` 基础布局，`figma-theme.css` 最新配色与字体，`app.js` 检测、状态机、绘制与双窗同步，`gestures.js` 举手判定与短暂丢帧容错。
